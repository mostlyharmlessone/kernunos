The code associated with this chapter requires version 4.3 of the SuperLU package.

There is a single executable that may be built using the makefile.

  • testSLUInterop uses set_precision.f90, sluInterop.f90, sortElements.f90, sparseAssign.f90, sparseOps.f90, sparseSort.f90, sparseTypes.f90, fortran_double_call_SuperLU.c, and SuperLU v4.3 as a library.
