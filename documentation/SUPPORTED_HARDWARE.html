Supported Hardware

This document refers to corneal topography machines which generate the data, NOT machines that can run kernunos. Kernunos is meant to run on a desktop machine.

The following list is in roughly chronological order and is not meant to be exhaustive or complete. Some of these machine do a lot more than topography of the anterior surface of the cornea, but that is outside the scope of this document. The information below is entirely from observation and public knowledge and may contain errors.

the list

Computerized Corneal Topographer (EH-270) (ca late 1980s). Placido disk technology with data measured by reflection off surface; slope based data. There were 22 mires and 36 to 360 radials. File types and export status unknown. Discontinued hardware as far as I know. I have no experience with this machine. Unsupported.

Corneal Modeling System by Computed Anatomy (ca late 1980s). Mentioned in the above discussion of accuracy, this machine also uses Placido disk technology with data measured by reflection off surface; slope based data. There were 32 mires and 256 radials. File types and export status unknown. Discontinued hardware as far as I know. I have no experience with this machine. Unsupported.

EyeSys technologies CAS Corneal Analysis System (ca.1990s) Placido disk technology with data measured by reflection off surface; slope based data. There are 16 mires and 360 radials. I have limited experience with this machine and little familarity with the data export and storage format. There are EY, PU, HX, PA, RA and XX prefix data files in the database directory. Only the RA and XX prefix data files are needed, in pairs, but the PU files can be read if present. There are at least two versions of RA and XX files, one with a header and colon delimited data, one with plain ASCII numbers. The header can also be found in an associated HX prefixed file with the extension .HDR (presumably for header) with no other data. If a PU prefixed file is found, I have only seen versions with a header and colon delimited data. EY files are undocumented binary data files. I have no documentation but assumptions can be made about the data available. Discontinued hardware as far as I know. Patient data files are in a common directory with unique names. Supported, reading XX, RA, PU, HX or HDR file if present

Alcon EyeMap EH-290 (1990s) Placido disk technology with data measured by reflection off surface; slope based data. There were 23 mires and reportedly 256 radials. File types and export status unknown. Discontinued hardware as far as I know, which does not mean it is not still in use. I have no experience with this machine. Unsupported but possible

Zeiss Atlas 900 (circa 1990) and 9000 (ca 2000) Placido disk technology with data measured by reflection off surface; slope based data. Data files: one has to export Model 900 files to Model 9000 (presumably the original machine software did not have this capability) because the 900 series has no direct ability to export files. One can then export 9000 data files "for research" into (.CSV) suffix files. Instructions: select exam, File/Export for Research, select CSV either comma delimited for semicolon delimited, comma delimited is preferred (semicolon delimited is only supported using sed in linux at this time). Prior to export, the data is in an undocumented proprietary format in binary which appears to be an embedded Embarcadero database (.ib) Limited documentation in the CSV files. There are 25 mires and 180 radials for the Atlas 900. There are 22 mires and 180 radials for the Atlas 9000. The model 9000 software can export Zernike coefficients as part of the data file. Exported patient data files have unique names. Supported, reading curvatures, pupil data and Zernike coefficients if present from export files, DICOM files (.DCM) not supported

Oculus Pentacam (2010s-present) Not a Placido disk machine: It is a Scheimpflug tomographer, using photography to reconstruct a 3-D image. Although this is a tomography machine, here we are only concerned with the anterior surface, i.e. topography. Files can be exported as comma separated value(CSV) files with .ELE or .CUR extensions as well as semicolon delimited versions with CSV extensions: ELE.CSV and CUR.CSV Instructions: .ELE .CUR ELE and CUR are generated by Loading a scan and Exporting data in PentaCam; NOT "Exporting exam" which exports an undocumented binary .U12 file. The exportable data are reported as 141 by 141 cartesian grids of 3D points which do not depend on the reflective surface, and can also measure corneal depth and posterior surface. Only one ELE or CUR or CSV version of ELE.CSV, CUR.CSV is needed. ELE and ELE.CSV files have elevations, CUR or CUR.CSV files have "sagittal/axial curvatures". It should be pointed out that the elevation data is supposedly primary with this machine and that the central elevations can frequently have equal adjacent measurements, with an effective flat local area with infinite curvature which can produce artifacts depending on how the data is used. Per the manufacturer, the newer machines including OCT also have CSV files for epithelial thickness which support the same format. Exported patient data files have unique names. Supported: note, only anterior surfaces and pupil data are read from ELE or CUR ASCII export files for comparison with Placido technology, OCT version also provides internal corneal layers, not used/supported here

Oculus Keratograph (2010s-present): Placido disk technology with data measured by reflection off surface; slope based data. There are 22 physical mires, although the data reported along 60 points along 100 half meridians. Advertisements state it analyzes 22,000 points. As with other manufacturer's advertisements, it is difficult to ascertain exactly what data is being referenced. The raw data for a Placido image at the pixel level could easily be in excess of 300,000 points, though the usable area might be closer to 100,000. I have no experience with this machine. The one machine I inspected used a proprietary U12 binary database similar to the Oculus Pentacam. However the manufacturer (Oculus) has proven responsive and does have documentation on some of the export files. They were even kind enough to send me documentation and an example file set. The machine also provides keratometric, iris and contact lens fitting data, not used here. Data is reported every 0.1 mm from the center at 0.0 to 6.0 mm, with sagittal and tangential curvatures as well as elevations, reported at 100 half meridians/radials, or every four grads. Clearly, just as with the PentaCam, these are processed points, not measured data, nonetheless versions of the files are available with or without extrapolated data, per the manufacturer. Exported patient data files each are in a different directory but all have the same name. Zernike data files are exported differently. Experimental support, limited testing on one file, reading curvatures CURVAT_F.O (includes extrapolated data) or CURVAT.O (without extrapolated data), elevations CORNEA_F.O CORNEA.O and pupil data PUPIL.O, CENTER.O if present from export files. There are also compressed "zipped" versions. Also reads ZERNIKE.TXT files with support for reading stored Zernike coefficeints correlating with an exam

Nidek OPD Scan III (2017) combines Placido disk corneal topography, wavefront aberrometry, autorefraction, keratometry, and pupillometry. There are (apparently) up to 33 or 39 mires (there are 6 partial mires horizontally) with 360 radials, though the machine settings allow using less. Multiple databases are an option; the format is undocumented. Some ASCII data files appear similar to the EyeSys formats. To access the data, save the data in an uncompressed database in a known location and look for files such as RA, PR, PE, ED and HT .DAT which are ASCII readable. These may be stored in a compressed RA .CAB or ED .CAB etc. archive, which can also be read. There are numerous other data files relating to autorefraction and CL fitting, images, demographics and other unknown files. There are only 23 mires in the ASCII files I have seen; the manual seems to imply that the number of rings is adjustable up to 33. Nidek RA files seem to be curvatures in units of radii (corresponding to EyeSys XX file) ED files contain data with apparent radii (corresponding to EyeSys RA file) but ASCII ED .DAT files may have 3 sets of numbers, "after DB_V3", "after DB_V4"...? Currently I am using the first set of 360. PE or PR files appear to be pupil diameters, similar to EyeSys PU, but some seem quite irregular. I am using PE files. ASCII HT files seem to be elevations, presumably computed. QV files are Q values for CL fitting per the manual. AR is unknown but possibly AutoRefract data. There are also binary files with similiar names and an ASCII header, also found in a CAB (Windows "cabinet") compressed archive. See the "Notes on OPD-III Nidek files", I have made many assumptions about the data being stored in an unusual packed BCD format. The binary form of the RA or ED files all appear to have 39 mires; there don't appear to be any HT binary files. Patient data files are in a common directory with unique names. Supported, reading ASCII RA,ED, PE .DAT or .CAB, HT .DAT, experimental support for binary files RA, ED, PE .DAT or .CAB,

VISIA (Topcon) CA-800 (2010's): Placido disk technology with data measured by reflection off surface; slope based data. 24 rings, 6200 measured points per the manual, suggesting 256 radials Advertisements state it analyzes over 100,000 points. As with other manufacturer's advertisements, it is difficult to ascertain exactly what data is being referenced. The raw data for a Placido image at the pixel level could easily be in excess of 300,000 points, though the usable area might be closer to 100,000. I have limited experience with this machine. Patient files can be exported as archived lzh files which contain a number of files, including what looks like topography data in a binary undocumented format, and ASCII configuration files and directories written in Italian. Manufactured by VISIA in Italy, acquired by Topcon (based in Japan) in 2021 Unsupported: see Notes on TopCon CA-800 files

VISIA (Topcon) Aladdin (2025): Placido disk technology as well as aberrometry, pupillometry and biometry. Appears to be essentially an updated version of the CA-800 with additional hardware and software features. Placido disk data measured by reflection off surface; slope based data, presumed 24 rings and 256 radials I have no experience with this machine. Manufactured by VISIA in Italy, acquired by Topcon (based in Japan) in 2021. Unsupported: see Notes on TopCon CA-800 files

Tomey TMS-4N (1990s to present) (previous models 1,2,3): Placido disk technology with data measured by reflection off surface; slope based data. There are reportedly 25 or 31 mires and 256 radials. File types and export status unknown, I have no experience with this machine. Papers written using data from this machine in the TMS-1 and TMS-2 version in the early 2000's suggest to me that the file types may have been human readable at some point. Unsupported

Bausch & Lomb Orbscan (1990s to present) Latest model IIz. Placido disk technology and slit-lamp images. Possibly 24 mires and 360 radials. The technology is not clear from the marketing. I have limited experience with this machine, but it has no apparent exportable data functions AFAIK. Undocumented binary proprietary database, appears to be an embedded Microsoft Access file, there may be other data files. Unsupported

Tracey Technologies iTrace (2010's to present) combines Placido disk corneal topography, wavefront aberrometry, autorefraction, keratometry, and pupillometry. There are 24 mires with 360 radials. It can export some summary data if Microsoft Excel is installed on the machine, (which is not typically included by the manufacturer). "Data" binary compressed with gzip appears to have mire data, aberrometry. As of 2025, this machine has become more popular, with a number of proprietary "indices" (e.g. DLI "dysfunction lens index", CPI "corneal performance" and QVI "quality of vision") featured in speaker's platforms. This continues the trend of summary novel undocumented measures of optical properties. I have limited experience with this machine. The data appears to be stored in a unified zip file for each patient containing a binary file named "Data".
Unsupported

Alcon Wavelight Vario Topolyzer(2020s): Placido disk technology with data measured by reflection off surface; slope based data, can also perform wavefront aberrametry, "capturing up to 88,000+ data points". The technology is not clear from the marketing on the website. File types and export status unknown, as well as what percentage of the 88000+ data points are topography of the anterior surface. Putting it in perspective, a typical Placido disk image has at most 3500-5000 points of data, with the PentaCam perhaps 15000 points for the anterior corneal surface, if we call the provided computed information "data". The raw data for a Placido image at the pixel level could easily be in excess of 300,000 points, though the usable area might be closer to "88,000+". Interestingly, associated with the Alcon Vario is a independent analysis program "Phorcides for Contoura". Although it is primarily meant for Alcon users with the Alcon Wavelight EX500 and an Alcon Vario Topolyzer, (per the website) apparently a Pentacam or G4 Schiempflug topographer can use "Phorcides for Contoura" https://phorcides.com/ to analyze PentaCam images as well, according to their webpage. Its purpose according to the website is as follows: "Phorcides is clinical decision support software. It is meant as an advisory tool to allow surgeons to consider the optical effects of topographic treatments and advise on the appropriate treatment for a patient. It provides analytic support to understand how and why treating topography affects a patient’s spherical and astigmatic Contoura treatment. It is meant to assist with calculations for primary LASIK treatments." The fact that a program such as Phorcides states that it can import Alcon Vario data as well as PentaCam data suggests that the Alcon Vario might be able export data in a usable format, although Alcon may have provided a proprietary binary exchange. I have no experience with this machine, nor Phorcides. Unsupported but possible

Heidelberg Engineering Anterion (2025) uses 1300 nm OCT (ocular coherence tomography) to measure the entire anterior segment, including of course the anterior corneal surface. Strictly speaking, this is a tomography machine, not just a topography machine. The marketing brochure states that 65 linear scans with "16,000 data points of the anteror and posterior corneal surface" are performed. The resolution of the images produced on this machine promoted in the brochures seems to be a different league than earlier technology. One claim is a resolution of 0.03 D for refractive power. As previously noted, without access to the actual data and methods it is hard to know how to independently test such claims. I have no experience with this machine. It wouldn't be hard for Heidelberg to follow the example of Zeiss and provide an Export for Research function for the height data measured; on the other hand, no other OCT machine (retina imaging, not cornea, including Heideberg Engineering's retina OCT machine) seems to have any data documentation or export functions. Unsupported

Historical notes

Some of the history of these machines is intertwined, for example:

In 1986 Joe Wakil founded EyeSys Technologies, Inc.
In 1997 Premier Laser Systems bought EyeSys Technologies; they then signed a licensing deal with Nidek in 1997 for the EyeSys technology.
In 1999 Dr. Wakil and others founded Tracey Technologies concentrating on ray tracing technology.
In 2000 Pro-Laser (German based company) was in negotiations with Premier to buy EyeSys, then Premier suspended the deal and filed Chapter 11
In 2001 Tracey Technologies (Dr Joe Wakil CEO), with the support of Marco Ophthalmic (a long term partner of Nidek among others) (re)acquired the EyeSys corneal topography product line from Premier Laser Systems

.. all of which supports that the above listed EyeSys, Nidek and Tracey Technology machines all use 360 (every degree) meridians and might share a common algorithmic pedigree. Published journal information on the Tracey iTrace machine's Placido system explicitly mentions that it uses 24 rings with 8640 points (360 meridians) and that it has a "built-in" EyeSys system. (as opposed to the 180 (every 2 degrees) meridians (favored by Zeiss) or 256 mires (e.g. Corneal Modeling System, Tomey, VISIA and possibly Alcon) or 100 meridians (every 4 grads) (presented/used by Oculus)) Of course using a common number for meridians is not evidence of common origin. VISIA founded in 1993 in Italy may well have no commonality with the Corneal Modeling System other than reading journal descriptions of its system in the literature at the time. Perhaps they were hoping for a universal standard to evolve.
