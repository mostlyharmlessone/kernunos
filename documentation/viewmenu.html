View Menu

The View Menu lets you select different ways to see the data. Auto redraw forces a redraw everytime a color or function option is changed. Options to show axes, surface normals central powers are available. By default the function shown is superposed upon the shape of the cornea as represented by its elevation, but the function shown can also be represented by a scaled elevation. The first example shows Lighting, Normals and Axes. THe second example shows Pupil, Angles and Powers. Partial transparency using the slider at the bottom shows the Pupil behind the central image. Note the previously loaded file to the viewer's left. shows the default with no lighting, transparency, angles or powers, which are only ever shown in the central figure. The third example shows the Operation of the Compare, creating the image to the viewer's right.
